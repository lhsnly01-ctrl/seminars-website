1. المقدمة (Introduction)

في عالم الأمن السيبراني الحديث، تواجه فرق التحقيق واستجابة الحوادث كميات هائلة من سجلات الشبكات والبيانات الواردة من الأجهزة والخوادم ونقاط النهاية (Workstations). يتمثل التحدي الأساسي في تعقيد العلاقات المتبادلة بين هذه الأنظمة، إذ غالباً ما ينتقل النشاط المشبوه أو البرمجيات الخبيثة (Malware) بخفية عبر أكثر من جهاز قبل الوصول إلى الهدف الحساس.

الفكرة الجوهرية: لتبسيط تحليل هذه الشبكات المعقدة نمثّل الأجهزة كعُقد (Nodes) والاتصالات وقنوات نقل البيانات كحواف (Edges) ضمن هيكل بيانات الرسم البياني (Graph). وهذا يتيح تطبيق خوارزميات الاستكشاف مثل BFS و DFS للإجابة عن السؤال المحوري: «إذا اشتبهنا بجهاز معين، فكيف نعرف كافة الأجهزة المرتبطة به؟»

2. الأهداف الرئيسية

  • تعريف الرسم البياني ومكوناته (العقد والحواف).
  • التمييز بين الحواف الموجّهة وغير الموجّهة في الشبكات.
  • توضيح كيف يساعد المسار البياني في تتبع الحركة الجانبية للمهاجم.
  • مقارنة خوارزميتي BFS و DFS واستخداماتهما السيبرانية.
  • تنفيذ مثال عملي بلغة بايثون وبيان حدود هذه الطريقة.

3. أساسيات الرسوم البيانية في الشبكات (Graph Basics)

الرسم البياني (Graph) هو هيكل بيانات رياضي غير خطي يتكون من عنصرين رئيسيين يعكسان واقع البنية التحتية لتكنولوجيا المعلومات:

  • العقدة (Node / Vertex): تمثل الكيانات الفردية داخل الشبكة، مثل الأجهزة الشخصية والخوادم (Servers) وقواعد البيانات أو حتى المستخدمين.
  • الحافة (Edge): تمثل الاتصال أو خط ارتباط البيانات والعلاقة بين عقدتين.

3.1 أنواع الحواف في الشبكات

  • اتصال بلا اتجاه (Undirected Graph): يعبّر عن اتصال ثنائي الاتجاه بين جهازين.
  • حواف باتجاه محدد (Directed Graph): تعبّر عن تدفق البيانات أو الاتصالات في اتجاه واحد، مثل طلب إرسال من العميل إلى الخادم.

4. تمثيل الشبكة (Network Graph Representation)

من خلال دمج سجلات الاتصالات (Connection Logs) وقواعد بيانات الأصول (Asset Databases) يمكن تحويل البنية التحتية للمؤسسة إلى خارطة بيانية تُظهر مساراً افتراضياً يبدأ عادةً من محطة عمل مخترقة وينتهي بقاعدة بيانات حساسة:

Workstation A→ Server B→ Database C

ملاحظة هامة: هذا الرسم يوضح علاقة ارتباط ومسار محتمل، ولا يُعتبر بحد ذاته دليلاً قاطعاً على وقوع اختراق دون تحقق أمني إضافي.

4.1 تمثيل الرسم في الذاكرة

الطريقة الشائعة هي قائمة الجوار (Adjacency List): لكل عقدة قائمة بجيرانها، وتُنفَّذ في بايثون بقاموس (Dictionary) كما في القسم 7. وهي مناسبة للشبكات الكبيرة قليلة الاتصالات لأن مساحتها تتناسب مع عدد العقد والحواف.

5. تحليل مسار الهجوم (Attack Path Analysis)

عند تتبع حركة المهاجمين داخل الشبكة، يعتمد المحللون على تتبع مسارات الحركة الجانبية (Lateral Movement)، وهي التقنيات التي ينتقل بها المهاجم من جهاز إلى آخر بعد الاختراق الأولي. وجود مسار بياني (مثل المسار الافتراضي E → D → B → A) يتيح للفريق التركيز الفوري على الثغرات المحتملة بدلاً من البحث العشوائي في آلاف السجلات.

E→D→ B→A

الفائدة الاستراتيجية: تحديد العلاقات والمسارات الخفية التي تستحق التحقيق الفوري وحماية الأصول الحساسة قبل تفاقم الحادث الأمني.

6. خوارزميات الاستكشاف (BFS و DFS)

لاستكشاف العقد والاتصالات داخل الرسم البياني للشبكة نستخدم خوارزميتين أساسيتين في هياكل البيانات:

الخوارزميةآلية العمل والخصائصالاستخدام السيبراني
BFS
(Breadth-First Search)		تستكشف الجيران الأقرب أولاً مستوى بمستوى، وتعتمد على هيكل الطابور (Queue).مثالية لإيجاد أقصر مسار بعدد الحواف في شبكة غير موزونة (أقل عدد قفزات للوصول إلى الهدف).
DFS
(Depth-First Search)		تتعمق في مسار واحد بالكامل قبل الرجوع، وتعتمد على المكدس (Stack) أو الاستدعاء الذاتي.ممتازة لاستكشاف كافة الفروع والمسارات المحتملة التي سلكها المهاجم داخل النظام.

تبلغ كلفة الخوارزميتين O(V + E) عند استخدام قائمة الجوار، حيث V عدد العقد و E عدد الحواف، أي أن كلاً منهما يزور كل عقدة وكل حافة مرة واحدة تقريباً.

7. تطبيق عملي بلغة بايثون (Python Implementation)

المثال التالي يستخدم BFS لاستكشاف الأجهزة المتصلة، ويتجنب التكرار باستخدام القاموس وقائمة الانتظار ومجموعة الزيارة:

from collections import deque

graph = {
    "Workstation A": ["Server B", "Laptop D"],
    "Server B": ["Database C"],
    "Laptop D": ["Server B"],
    "Database C": [],
}

def bfs(graph, start):
    seen = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        print(f"Visited: {node}")
        for neighbor in graph[node]:
            if neighbor not in seen:
                seen.add(neighbor)
                queue.append(neighbor)

bfs(graph, "Workstation A")
# Visited: Workstation A
# Visited: Server B
# Visited: Laptop D
# Visited: Database C

7.1 إيجاد أقصر مسار بين جهازين

بتسجيل «الأب» (parent) لكل عقدة يمكن إعادة بناء المسار من نقطة الاشتباه إلى الأصل الحساس:

def shortest_path(graph, start, target):
    parent = {start: None}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == target:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for neighbor in graph[node]:
            if neighbor not in parent:
                parent[neighbor] = node
                queue.append(neighbor)
    return None    # لا يوجد مسار

print(shortest_path(graph, "Workstation A", "Database C"))
# ['Workstation A', 'Server B', 'Database C']

7.2 نسخة DFS

def dfs(graph, node, seen=None):
    if seen is None:
        seen = set()
    seen.add(node)
    print(f"Visited: {node}")
    for neighbor in graph[node]:
        if neighbor not in seen:
            dfs(graph, neighbor, seen)
    return seen

dfs(graph, "Workstation A")
# ترتيب الزيارة: A ثم B ثم C ثم D

8. الاستخدامات والحدود في الأمن السيبراني

تُستخدم الرسوم البيانية على نطاق واسع في البحث عن التهديدات (Threat Hunting) والاستجابة للحوادث (Incident Response) لفهم الروابط والأنماط المشبوهة. غير أن دقة النتائج تبقى رهناً بدقة السجلات المستخرجة وجودة تعريف الحواف والسياق الأمني المحيط.

الفوائدالحدود
تحديد الأجهزة المرتبطة بجهاز مشتبه به بسرعةتعتمد على جودة السجلات؛ سجل ناقص يعني حافة مفقودة
إيجاد أقصر مسار نحو الأصول الحساسةوجود مسار لا يعني أن الهجوم مرّ منه فعلاً
توجيه التحقيق بدل البحث العشوائيتتطلب تعريفاً صحيحاً لما يُعد حافة (اتصال، جلسة، صلاحية)

9. الخاتمة

الرسوم البيانية تدعم التحقيق وتسهّل كشف مسارات الاختراق، إذ تحوّل شبكة معقدة من السجلات إلى خارطة يمكن استكشافها بخوارزميات BFS و DFS. لكنها وحدها لا تثبت الهجوم بالكامل دون أدلة جنائية رقمية (Digital Forensics) مكمّلة.
